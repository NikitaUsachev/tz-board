# ТЗ на мероприятия

Канбан-доска технических заданий: залы, звук, свет, видео.

- Техники открывают ссылку и читают ТЗ без входа.
- Администраторы входят по ссылке из письма («Вход для администраторов») и редактируют.
- Данные хранятся в Supabase (проект `tz-board`), права доступа задаются правилами RLS: писать могут только адреса из таблицы `admins`.

Список администраторов редактируется в приложении: «Настройки» → «Администраторы».
Схема базы — в `schema.sql`.
