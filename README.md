# ТЗ на мероприятия

Приложение для подготовки ТЗ по залам и отделам. Статический сайт на JavaScript, Supabase для данных и авторизации.

- Администраторы входят по почте и паролю, работают с общей доской, заявками на доступ и ТЗ.
- Техники открывают конкретное ТЗ без входа. Имя спрашивается при первой отметке выполнения и запоминается в браузере. Имя не является проверенной учётной записью.
- При сохранении проверяется версия ТЗ. Независимые правки объединяются; спорные данные требуют выбора. Безусловной перезаписи документа нет.
- Удалённые ТЗ перемещаются в корзину и могут быть восстановлены. Физически строки и сохранённые вложения через интерфейс не удаляются.
- Локальные черновики помогают восстановить несохранённые правки в том же браузере. Они не заменяют серверные резервные копии.
- Номер версии и история изменений доступны внизу доски администратора.

## База и развёртывание

Читайте DEPLOY.md. Изменения SQL в GitHub не применяются к действующей Supabase автоматически.
schema.sql — базовая схема, а не полный дамп существующего проекта. Для серверной защиты v28 подготовлен migrations/20261101_safety.sql.
До его применения требуется проверить реальные RPC, RLS и Storage-политики запросами inspect-supabase.sql.
Существующие RPC отметок и заявок не представлены полностью в репозитории; аудит их прав требует вывода диагностики.

## Проверки

node --check app.js
node tests/regression.cjs
node tests/concurrency.cjs
node tests/safety.cjs
node tests/ui.cjs

Сборка и установка npm-пакетов не требуются. Тесты используют встроенные модули Node.js и модели DOM, сети и базы.
