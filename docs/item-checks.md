# 28.18 — два этапа у каждой позиции

Свет, Звук, Видео и Сцена: каждая строка оборудования, а также каждый пункт параметров основной и дополнительных сцен имеет две независимые отметки «В зале» / «Смонтировано». У каждой — своё имя и время. В «Дополнительно» остаётся одна отметка выполнения.

Общие галочки блоков из 28.17 убраны из интерфейса. Их сохранённые данные не преобразуются в отметки отдельных позиций. Прежняя отметка позиции остаётся как «Смонтировано»; присутствие записывается отдельно с префиксом arrival:. Смена ID изменённой позиции или параметров сцены сбрасывает оба видимых статуса. Прогресс и доступность кнопки готовности зала в интерфейсе учитывают оба этапа.

На телефоне подписи находятся внутри крупных областей нажатия и расположены вертикально; название, количество и примечание остаются над ними. Вложенных label нет, изменение одной отметки не переключает соседнюю.

Развёртывание: migrations/item-arrival-checks.sql до публикации frontend. Старый клиент продолжает работать. Миграция не удаляет данные.

Проверки: npm test — 74 успешно. tests/item-arrival-checks.sql проверяет независимое сохранение/снятие, имя/время, совместимость прежних отметок, дополнительные сцены и отказы для отсутствующих позиций, пустого имени, удалённого мероприятия и категории Дополнительно. Тесты выполняются с ROLLBACK без отправки сообщений. Браузерный сценарий tests/browser/block-checks.cjs обновлён для отметок отдельных позиций и запускается в CI.
