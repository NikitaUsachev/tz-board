# Этапы работ по блокам — 28.17

Свет, Звук, Видео и Сцена получают независимые подтверждения «Всё оборудование в зале» и «Монтаж завершён». Отметки отдельных позиций сохраняют прежний смысл. Этапы видны и при свёрнутом блоке; пустые блоки и «Дополнительно» их не показывают. На узком экране статусы расположены вертикально. Для подтверждений сохраняются полное имя и время.

Состав оборудования, количество и параметры сцен при изменении сбрасывают оба подтверждения соответствующего блока; изменения названия мероприятия не сбрасывают их. Другие залы и блоки не затрагиваются. Общая кнопка готовности зала продолжает использовать существующий чек-лист.

## Развёртывание

1. Применить migrations/block-work-checks.sql к Supabase.
2. Выполнить tests/block-work-checks.sql целиком: тест откатывает изменения.
3. Опубликовать frontend. Изменения обратносовместимы со старым клиентом.

Серверный метод сохраняет отметки в существующей таблице checks. Доступ по ссылке на ТЗ соответствует модели существующих отметок техников. Метод проверяет действующее мероприятие, выбранный зал, категорию, этап, оборудование и имя; служебная функция сброса не доступна клиентам. Данные ТЗ и старые отметки миграция не удаляет.
